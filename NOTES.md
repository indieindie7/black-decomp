# Black (PS2, Criterion 2006) decomp notes (names + notes only; no game data)

## Disc and ELF (2026-10-18)
- NTSC US release (SLUS-21376), own copy. Disc tree: CHARS, DATA, EXPORT, GLOBDATA.BIN, IOP, LANGUAGE, LEVELS (GLOBAL + LEVEL_00..08), SOUND, SLUS_213.76 (585 files). SYSTEM.CNF: BOOT2 = cdrom0:\SLUS_213.76;1.
- SLUS_213.76 (3,371,868 B): entry 0x00100008, PT_LOAD 0x00100000 filesz 0x30e580 memsz 0x39bfbc. Sections: .text 0x00100000 size 0x296f48, .vutext 0x00396f50 (0x253e0, about 90 .DVP.overlay VU1 microprograms + .DVP.ovlytab), .data 0x003bc380, .rodata 0x003f2280, .gcc_except_table (C++ exceptions), .sdata 0x0040d980, .bss 0x0040ec80 (0x8d33c), .vubss.
- IOP: DBCMAN, DS2O, DSPROUTE, GTFSCDVD, MC2_D, RWA, SIO2D (Criterion IOP drivers) + IOPRP300.IMG.

## Ghidra (12.1.4)
- Imported as MIPS:LE:64:default (no R5900 variant): 8,024 functions, 453 strings; EE MMI / VU0 macro ops decode as bad instructions and are named from context as vector / DMA code.

## Naming round 1 (2026-10-18)
- CsDumpAll dump (8,024 functions, 4.2 MB; hints for 8,024, 297 with strings) -> `trimdump.py` -> `slice.py 12` (491-752 functions per slice) -> one naming agent per slice with `ghidra/naming/prompt_r1.txt`.
- The first output of one slice was generated by a script (shape-only names, all provisional): rejected and redone by hand; the no-script rule at the end of the prompt comes from that.
- `dedupnames.py`: names unique across slices; 1 function nobody named was added by hand (0x00128008, a VU0 ray/plane parameter test).
- ApplyNames (hand mode): 8,019 named (5 were already named by analysis); export `ghidra/funcinfo_SLUS.tsv`: 8,024 functions, 0 FUN_, 3,171 provisional. Five names still contain "FUN_" as text (call wrappers, e.g. ctl_CallFUN_00135550): fix in round 2.
